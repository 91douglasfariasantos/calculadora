# 🧮 Calculadora Douglas

Projeto de uma calculadora simples, moderna e responsiva, desenvolvida com **HTML, CSS e JavaScript**.  
A interface utiliza um estilo visual inspirado em **Neumorphism**, com sombras suaves, botões arredondados e layout limpo.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📌 Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Botão de limpar tudo `AC`
- Botão de apagar último dígito `DEL`
- Suporte para números decimais
- Layout responsivo para telas menores

## 🎨 Layout

A calculadora possui um design moderno com:

- Fundo em tom claro
- Efeito de profundidade nos botões
- Display com sombra interna
- Botão de igualdade destacado
- Operadores com cor personalizada
